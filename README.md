# Titus Trails

A community-first walking information site built with Next.js 16, React 19 and Tailwind CSS 4. Regional pages are introductions, not verified routes, bookings or endorsements. Always obtain local permission and guidance where required. You are a guest.

## Development

```sh
npm ci
npm run typecheck
npm run lint
npm run build
npm audit
npm run dev
```

## Responsible deployment

The supplied TraveLand lite template license expressly prohibits commercial use and removing footer credit. See `TEMPLATE-LICENSE.txt` and obtain the necessary license before commercial deployment. The original archive is retained in the repository.

No verified WhatsApp number, contact address, reCAPTCHA keys, moderation service or authentication backend was provided. These features are not fabricated. Saved regions and private notes use browser local storage, not an account. Public submissions and guide listings are not enabled. A production operator should establish community consent, a verified contact channel, moderation, data retention policies and server-side CAPTCHA verification before enabling forms. Full translations require community review; only navigation is translated currently. The site does not use analytics.

Vercel is configured for `cdg1` and security headers. Images are illustrative, not representations of specific trails. See `image-credits.md`.
